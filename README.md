## APIs

### Flux CD
Flux is a set of continuous and progressive delivery solutions for Kubernetes that are open and extensible, enabling GitOps-based automation for keeping Kubernetes clusters in sync with sources of configuration like Git repositories. Flux is built on Kubernetes' API extension system and is controlled through Custom Resources (CRDs) such as `GitRepository`, `Kustomization`, and `HelmRelease` rather than a standalone REST/HTTP API.
